# COMP 171 Gym

Study app for COMP 171 (Principles of Computer Science I, Python) at Ithaca College: lessons, glossary flashcards, an adaptive quiz, a trace lab, a TDD lab, and timed practice exams.

## Use it

- **Online:** https://chanakya009-ctrl.github.io/comp171-gym/ (after GitHub Pages is turned on)
- **Offline:** download `index.html` and double-click it.

Everything is in that one file. Your progress is saved in the browser you use it in.
